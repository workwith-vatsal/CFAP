# CFAP — Cognitive Feedback Analytics Platform

## Overview

CFAP (Cognitive Feedback Analytics Platform) is an AI-powered customer feedback analytics and business intelligence platform.

The platform enables organizations to upload customer feedback datasets and obtain:

- Sentiment analysis
- Emotion detection
- Topic modeling
- Explainable AI insights
- Interactive business intelligence dashboards
- Dataset-driven business insights
- Anonymous aggregated benchmarking
- AI-assisted analysis
- Automated business reports

## Core AI Technologies

- BERT — Sentiment Analysis
- DistilRoBERTa — Emotion Detection
- BERTopic — Topic Modeling
- SHAP — Explainable AI

## Platform Architecture

CFAP is designed as a multi-user web application consisting of:

- Modern web frontend
- FastAPI backend
- PostgreSQL database
- Python-based AI/ML processing
- Python-based Business Intelligence layer
- AI Assistant
- PDF reporting system
- Administrative and audit systems

## Dataset Independence

CFAP is designed to process user-provided datasets dynamically.

Research datasets used for evaluating the methodology are not hard-coded into the application.
